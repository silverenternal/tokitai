# 我的工具集

这个工具集包含天气查询和数学计算功能。

## 工具列表

### 天气工具

#### get_weather
- **描述**: 查询指定城市的天气
- **参数**:
  - `city` (string, 必需): 城市名称，如 "北京"、"上海"
- **返回**: 天气描述字符串
- **示例**:
  ```json
  {"city": "北京"}
  ```
  返回：`"北京：晴朗，温度 25°C，湿度 40%"`

#### get_weather_batch
- **描述**: 获取多个城市的天气
- **参数**:
  - `cities` (array, 必需): 城市名称列表
- **返回**: 每个城市的天气描述列表
- **示例**:
  ```json
  {"cities": ["北京", "上海", "广州"]}
  ```
  返回：`["北京：晴朗，温度 25°C...", "上海：多云，温度 22°C...", ...]`

### 计算器工具

#### add
- **描述**: 两个数相加
- **参数**:
  - `a` (integer, 必需): 第一个数
  - `b` (integer, 必需): 第二个数
- **返回**: 两数之和
- **示例**:
  ```json
  {"a": 10, "b": 20}
  ```
  返回：`30`

#### subtract
- **描述**: 两个数相减
- **参数**:
  - `a` (integer, 必需): 被减数
  - `b` (integer, 必需): 减数
- **返回**: 两数之差
- **示例**:
  ```json
  {"a": 50, "b": 30}
  ```
  返回：`20`

#### multiply
- **描述**: 两个数相乘
- **参数**:
  - `a` (integer, 必需): 第一个数
  - `b` (integer, 必需): 第二个数
- **返回**: 两数之积
- **示例**:
  ```json
  {"a": 6, "b": 7}
  ```
  返回：`42`

#### divide
- **描述**: 两个数相除
- **参数**:
  - `dividend` (integer, 必需): 被除数
  - `divisor` (integer, 必需): 除数
- **返回**: 商，如果除数为零则返回错误
- **注意**: 除数不能为零
- **示例**:
  ```json
  {"dividend": 100, "divisor": 5}
  ```
  返回：`20`

#### square
- **描述**: 计算平方
- **参数**:
  - `n` (integer, 必需): 要计算平方的数
- **返回**: n 的平方
- **示例**:
  ```json
  {"n": 5}
  ```
  返回：`25`
