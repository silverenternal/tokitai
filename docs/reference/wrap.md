# `#[wrap]`

> Mark an `impl` block whose methods forward to a wrapped client type.
> `#[wrap]` is `#[tool]` with an explicit `methods = [...]` allow-list
> and a generated `new(client) -> Self` constructor — ideal for
> exposing a third-party API client as AI tools.

## Syntax

```rust,ignore
#[wrap(client = InnerType, methods = [method_a, method_b], field = "client")]
impl MyWrapper {
    pub fn method_a(&self, ...) -> ... { /* body */ }
    pub fn method_b(&self, ...) -> ... { /* body */ }
}
```

`#[wrap]` is **block-level** and goes on an `impl` block. It accepts
three arguments and shares 100% of the codegen pipeline that
`#[tool]` uses — the only thing it adds is a `new(client)` constructor
and a methods allow-list.

## Arguments

| Argument | Type | Default | Description |
|---|---|---|---|
| `client` | `Type` | _required_ | The inner-client type. Must match a field on the wrapper struct. |
| `methods` | `[Ident]` | _required_ | The method names to expose as tools. |
| `field` | `&str` (→ `Ident`) | `"client"` | The field name on the wrapper struct. |

`client` and `methods` are both required and must appear exactly
once. `field` is optional; the default is the literal identifier
`client`. The `methods` list must be non-empty (use `#[tool]` if you
want every public method).

## Examples

### Minimal

```rust,ignore
use tokitai::wrap;

pub struct InnerClient;

pub struct MyClient {
    pub client: InnerClient,
}

#[wrap(client = InnerClient, methods = [ping])]
impl MyClient {
    pub fn ping(&self) -> bool { true }
}

fn main() {
    let c = MyClient::new(InnerClient);
    let v = c.call_tool("ping", &serde_json::json!({})).unwrap();
    assert_eq!(v, serde_json::json!(true));
}
```

### Common usage

```rust,ignore
use serde::{Deserialize, Serialize};
use tokitai::wrap;

#[derive(Clone)]
pub struct InnerClient { base_url: String }

pub struct GitHubClient {
    pub client: InnerClient,
}

#[derive(Serialize, Deserialize)]
pub struct User { pub login: String, pub id: u64 }

#[wrap(client = InnerClient, methods = [get_user, list_repos])]
impl GitHubClient {
    /// Look up a GitHub user by login.
    pub fn get_user(&self, login: String) -> Result<User, String> {
        if login.is_empty() {
            return Err("login must not be empty".into());
        }
        Ok(User { login, id: 42 })
    }

    /// List the public repositories owned by `owner`.
    pub fn list_repos(&self, owner: String) -> Result<Vec<String>, String> {
        Ok(vec![format!("{owner}/hello")])
    }

    /// Not listed in `methods = [...]` → not a tool.
    pub fn health(&self) -> bool { true }
}
```

### Edge case

Override the field name when the wrapper struct uses a different
identifier than `client`:

```rust,ignore
use tokitai::wrap;

pub struct Http { /* ... */ }

pub struct Api {
    pub http: Http,        // not `client`
}

#[wrap(client = Http, methods = [do_thing], field = "http")]
impl Api {
    pub fn do_thing(&self) -> String { "ok".into() }
}
```

If a method listed in `methods = [...]` is not present (or not `pub`)
in the impl block, the macro emits a `compile_error!` naming the
missing method.

## Generated code

`#[wrap]` emits exactly the same artifacts as `#[tool]` —
`__TOOL_DEF_*` functions, `__call_*` wrappers, `call_tool` /
`call_tool_sync` dispatchers, the `__get_tool_definitions` lazy init,
`__TOOL_COUNT`, `configure_tool`, `impl ToolProvider`, `impl
ToolCaller` — **plus** a generated `new` constructor.

The constructor:

```rust,ignore
/// Construct a new wrapper around the given inner client.
///
/// Generated by `#[wrap]`. Equivalent to a hand-written
/// `Self { #client_field }` constructor; provided so the
/// user does not have to write it for every wrapped type.
#[allow(dead_code)]
pub fn new(client: InnerClient) -> Self {
    Self { client }
}
```

The `__get_tool_definitions` function (omitting the per-tool
constants which are identical to `#[tool]`):

```rust,ignore
#[allow(dead_code)]
fn __get_tool_definitions() -> &'static [::tokitai_core::ToolDefinition] {
    static TOOLS: ::std::sync::LazyLock<::std::vec::Vec<::tokitai_core::ToolDefinition>> =
        ::std::sync::LazyLock::new(|| {
            let mut defs = ::std::vec::Vec::from([
                <GitHubClient>::__TOOL_DEF_GET_USER().clone(),
                <GitHubClient>::__TOOL_DEF_LIST_REPOS().clone(),
            ]);
            for def in &mut defs {
                let configs = ::tokitai_core::GLOBAL_CONFIG_REGISTRY.get(&def.name);
                if !configs.is_empty() {
                    def.apply_configs(&configs);
                }
            }
            defs
        });
    &TOOLS
}
```

The two trait impls (these are the only items emitted by `#[wrap]`
that differ in shape from `#[tool]`):

```rust,ignore
impl ::tokitai_core::ToolProvider for GitHubClient {
    fn tool_definitions() -> &'static [::tokitai_core::ToolDefinition] {
        Self::__get_tool_definitions()
    }
    fn tool_count() -> usize { Self::__TOOL_COUNT }
}

impl ::tokitai_core::ToolCaller for GitHubClient {
    fn call_tool(
        &self,
        name: &str,
        args: &::tokitai_core::serde_types::Value,
    ) -> Result<::tokitai_core::serde_types::Value, ::tokitai_core::ToolError> {
        self.call_tool(name, args)
    }
}
```

## Interactions

- **With `#[delegate]`**: methods on the same `#[wrap]` impl block can
  be `#[delegate]`-marked; the `methods = [...]` list still names
  which of them become tools. See [`delegate.md`](delegate.md).
- **With `#[retry]` / `#[rate_limit]` / `#[circuit_breaker]`**:
  the resilience decorators compose with the user-written method body
  the same way they do under `#[tool]`. See the wrap-architecture
  [Composition rules](../wrap-architecture.md#5-composition-rules).
- **With `config!`**: the generated `__get_tool_definitions` consults
  the registry. See [`config.md`](config.md).
- **Re-export**: `#[wrap]` is re-exported from `tokitai` as
  `tokitai::wrap`.

## Errors

`#[wrap]` surfaces errors as `compile_error!` tokens:

| Trigger | Message |
|---|---|
| `client` not given | `"missing `client = TYPE` in `#[wrap(...)]`"` |
| `methods` not given | `"missing `methods = [name1, name2, ...]` in `#[wrap(...)]`"` |
| `methods = []` | "`methods = [...]` must list at least one method; use `#[tool]` if you want every public method" |
| A method in `methods` is not present (or not `pub`) in the impl block | `"method `<name>` listed in `methods = [...]` was not found in the impl block (note: it must be `pub` and have a non-`__` name)"` |
| `client = TYPE` repeated | `"`client` specified more than once"` |
| `methods = [...]` repeated | `"`methods` specified more than once"` |
| `field = "x"` where `x` is not a valid Rust ident | `"invalid `field = "x"`: expected a valid Rust identifier"` |
| Unknown `#[wrap]` key | `"unknown `#[wrap]` argument `<key>`; expected `client`, `field`, or `methods`"` |
| Internal parser roundtrip failure | `"internal `#[wrap]` error: generated item failed to parse: <syn err>"` |
